# CPU 配额内核准备材料

此目录仅包含固定源码提交信息和 CFS bandwidth 配置片段，不包含内核二进制、启动镜像、设备备份或签名材料。`source-lock.json` 保存准备阶段的基线信息；`flashable: false` 表示这些文件本身不是可刷入交付物，不代表维护设备当前没有启用配额。

`tools/prepare_cpu_kernel.py` 要求使用匹配且干净的源码树，以及自行核验的设备基线目录；它生成独立配置和缺失项报告，不刷写手机。准备方法、配套驱动 ABI 风险和已完成的设备验收见 [CPU 配额说明](../docs/cpu-quota.md)。单独开启配置并替换 boot 不能代替外部模块兼容检查。

本仓库配置与准备工具沿用项目 Apache-2.0 许可。链接指向的 Linux/LineageOS 内核及外部驱动保留各自上游许可证；本目录不重新授权这些源码，也不提供维护设备的私有恢复镜像。
