# 功能扩展验收清单

实施顺序：开屏广告 → 息屏与后台服务 → 类型化情景模式 → 跨应用启动 → 真实推送、资源趋势与配置管理。

每一阶段必须区分实现、自动测试、实机验收；未完成项不能宣称已支持。

- [x] 逐应用开屏适配及跨版本入口检查：QQ 音乐、知乎、京东、小红书、高德地图、bilibili、淘宝；各应用的实测边界见 [开屏广告](splash-ads.md)。
- [ ] 异常自动暂停的实机故障注入验收（逻辑及单元测试已完成）。
- [x] 息屏 60 秒清理缓存进程，音乐、导航、下载豁免；逐应用强停为显式选择。
- [x] 后台服务可视化与组件级启动策略；实现和实机边界见 [后台管理](background-management.md)。
- [ ] 屏幕、前后台、充电、电量、网络、定时、推送事件；组合条件与固定动作。
- [ ] 跨应用前台询问、后台拒绝，保留系统必要流程和明确例外。
- [ ] 用户手动触发真实消息，分别记录实际推送与合成测试证据。
- [ ] CPU、RSS、网络及策略事件七天趋势；不估算省电百分比。
- [ ] 配置复制、重命名、删除、差异、导入与导出。

新功能默认关闭并保留旧策略语义。升级前备份；所有配置具有可视化与 CLI 控制。控制服务使用本地 IPC。迁移覆盖所有配置方案，保留内部冲突检查。本轮不刷内核，不修改 Root 隐藏及钱包快捷键。

广告适配只拦截开屏路径，不整体禁用 SDK。版本变化不直接停用；签名和必需入口结构匹配则继续尝试，入口不匹配时放行并提示适配。没有出现广告不能作为拦截成功证据；必须记录匹配入口和调用证据，以及对照启动。
